# Alquileres

[English](README.md)

Prototipo de catálogo de alojamientos deprecado, reemplazado por Modo Playa. Se conserva como referencia de la interfaz Angular original.

## Stack

Angular · TypeScript · SCSS.

## Alcance y configuración

Contiene componentes de catálogo como tarjetas de alojamientos, cabecera y barra lateral. Este repositorio no implementa los contratos de la plataforma Modo Playa actual.

## Desarrollo local

Usar un entorno Node.js compatible con package.json y el lockfile de dependencias, cuando exista.

```sh
npm install
npm start
npm run build
npm test
```
